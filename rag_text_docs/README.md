# RAG Model 1: Plain-Text Documents (HR Policy Knowledge Base)

Retrieves over 5 plain-text HR policy documents (`data/*.txt`): remote
work, leave, expense, IT security, and onboarding.

```bash
python build_and_query.py "How many PTO days do employees get per year?"
```

See the top-level [README](../README.md) for how retrieval and generation
work.
